# 📊 Youth Trends Analysis

**An end-to-end data analytics project that uncovers the pulse of Gen Z India.**  
From digital habits to career dreams, this project dives deep into the real voices of today's youth using modern tools and smart visual storytelling.

---

## 🔍 Project Overview

This project analyzes youth trends with a focus on:

- 📱 **Social Media Usage vs. Mental Health**
- 💰 **Financial Habits & Investment Behavior**
- 🎯 **Analysing the behavious Towards spending**
- 💍 **Marriage Preferences by Gender & Occupation**
- 💬 **Openness to Mental Health Issues**

## 🧠 What I Learned

One key takeaway was that **correlations found in Python don’t always hold up visually in BI tools** after applying slicers.  
For example, I observed a pattern between **overweight individuals and high sugar levels**, and **underweight individuals with very high sugar levels** in Python. But when filtered by area (rural/urban) in Power BI, the correlation weakened.  
This taught me the importance of **validating insights in different contexts and tools** and avoiding assumptions based solely on initial analysis.
